# over-caution: neuralgcm, dinosaur and dm-haiku all depend on jax without an upper
# bound, and all three track JAX's moving API. An unpinned "pip install neuralgcm"
# resolves cleanly, exits 0, and produces an installation that cannot unpickle its own
# checkpoints:
#
#   jax too new  -> ShapedArray.__new__() got an unexpected keyword argument 'named_shape'
#   jax too old  -> module 'jax' has no attribute 'shard_map'                 (dinosaur)
#   in between   -> module 'jax.core' has no attribute 'take_current_trace'   (dm-haiku)
#
# This set was found by resolving the whole tree as it stood on 2025-02-01
# (uv pip install --exclude-newer 2025-02-01 neuralgcm) and verified by loading the
# packaged TL63 checkpoint. To move it forward, re-resolve at a later date and re-verify
# rather than bumping individual packages.
#
